# ALPHONSA SPICES website

Responsive static website for GitHub Pages. Includes:
- Idukki plantation-inspired green and cream design
- Product cards for Cardamom, Pepper, Coffee Beans, Clove and Masalas
- WhatsApp enquiry links
- Mobile navigation

## Preview on Mac
1. Extract the ZIP.
2. Open `index.html` in Safari or Chrome.
3. Internet is needed for Google Fonts and the remote photos.

## Publish with GitHub Pages
1. Upload the contents of this folder (not the ZIP) to the root of your public GitHub repository.
2. Go to Settings → Pages.
3. Choose Deploy from a branch → `main` → `/ (root)` → Save.
4. Connect your custom domain after the domain registration is confirmed and DNS records are configured.

## Before publishing
Please verify the phone numbers, address and Instagram handle in `index.html`. Photos are loaded from Unsplash and require an internet connection. The website does not process payments or store orders; WhatsApp links open a message to the business.
